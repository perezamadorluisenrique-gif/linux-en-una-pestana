Linux in a tab

A 32-bit RISC-V emulator (RV32IMA) written from scratch in TypeScript boots no-MMU Linux 6.1 inside this page, with no server and no plugins. An eight-chapter course (in Spanish) explains it piece by piece.

Try it

Press «Boot» and wait for login: (a few seconds; the image is 3.5 MB). User root, no password. Try uname -a, ls / or cat /proc/cpuinfo.

The code

Everything is in the repository: the CPU (src/cpu.ts), a fast WebAssembly engine generated from TypeScript (src/fast.ts), the devices, the device tree and the tests (76 riscv-tests and booting Linux in Node and in Chromium).
